# Tinybatch Documentation

Welcome to the official documentation for **Tinybatch**.

Tinybatch is a collection of high-performance, precision-focused batch processing tools designed for modern developers who appreciate a retro aesthetic.

## Why Tinybatch?

- **Fast**: Built on modern web standards (Nuxt 4, WASM).
- **Private**: Most tools process data locally in your browser.
- **Simple**: No bloat, just the functionality you need.
