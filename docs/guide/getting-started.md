# Getting Started

Learn how to integrate Tinybatch tools into your workflow.

## Installation

Tinybatch tools are available as web applications on [tinybatch.dev](https://tinybatch.dev) or can be used via our experimental CLI.

### Web Usage

Most tools are "zero-install". Simply browse to the tool page and drag-and-drop your files.

### CLI (Coming Soon)

```bash
npm install -g @tinybatch/cli
```
